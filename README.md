# iGaming Fraud & Risk Analytics

SQL + Power BI portfolio project focused on iGaming transaction analysis, player behavior, business performance and risk analytics.

## Project Overview

This project analyzes a large synthetic iGaming dataset covering player activity, wallet transactions, revenue, bonuses, segmentation and risk indicators.

The objective is to demonstrate practical skills in:

- SQL data preparation and transformation
- Power BI data modeling and dashboard development
- Fraud and risk-oriented analysis
- Player segmentation and behavioral analysis
- Business performance analysis
